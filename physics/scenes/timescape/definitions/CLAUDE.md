# physics/scenes/timescape/definitions/

- `deceleration` is proved on power laws: a size growing as t squared has q = -0.5, as
  the square root +1, a straight line 0. Read q only beside that.
- It fits a quadratic over the whole span and reads q at mid-span; a size that does not
  move gives NaN, never 0.
- `KNOWN_Q` is a measured number to read beside, not a target to tune to.
