# Axiom 5, logic

`spread.py`: hands the pull on by one neighbour. `fall.py`: the pull's slope adds to each volume's flow. `squeeze.py`: each joint's pull, push, distance and axis into `own_squeeze`. `press.py`: the squeeze turns the joint's facing phases. `lumps.py`: `grown`, `region`, `fuller`, `moving`, `two_lumps`. `staging.py`: `copy_of`, `packed`. `line.py`: `calm_line`, the bench.

- Order in a step: `spread`, `fall`, `squeeze`, then `make` and `press`.
- A fresh store's pull is 0: nothing is squeezed until the pull arrives.
- A collapsed joint keeps its distance and is not squeezed.
- `lumps.py` imports the engine's door; the door must not import it.
- Three layers take 345 steps: tests share one patch (`physics/conftest.py`).
