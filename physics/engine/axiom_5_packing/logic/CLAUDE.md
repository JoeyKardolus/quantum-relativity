# Axiom 5, logic

`between.py`: the volumes, the way between each two through the cells' sizes. `pull.py`: all pairs on the host; writes `cell_pull` (depth), adds to `cell_flow`. `squeeze.py`: each joint's pull, push, distance, axis. `press.py`: the squeeze turns the joint's facing phases. `lumps.py`, `staging.py`: staging. `line.py`: the benches, the window's scenes.

- Order in a step: `pull`, `squeeze`, then `make` and `press`.
- A fresh store's pull is 0: nothing has arrived.
- `cell_past` lives on the host.
- A volume must never enter its own sum.
- A collapsed joint keeps its distance and is not squeezed.
- `lumps.py` imports the engine's door; the door must not import it.
- Tests share one grown patch (564 steps).
