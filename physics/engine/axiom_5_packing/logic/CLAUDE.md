# Axiom 5, logic

`spread.py`: hands the pull on by one neighbour. `squeeze.py`: each joint's pull, push, distance and axis into `own_squeeze`. `press.py`: the squeeze turns the joint's facing phases. `lumps.py`: `grown`, `region`, `fuller`, `moving`, `two_lumps`. `staging.py`: `copy_of`, `packed`.

- Order in a step: `spread`, `squeeze`, then `make` and `press`.
- A fresh store's pull is 0: nothing is squeezed until the pull arrives.
- A collapsed joint keeps its distance and is not squeezed.
- `lumps.py` imports the engine's door; the door must not import it.
- Only a check or a scene's start stages; no step does.
- Three layers take 1,315 steps: tests share one patch (`physics/conftest.py`).
