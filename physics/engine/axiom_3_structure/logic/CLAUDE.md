# Axiom 3, logic

`starts.py` and `first_volume.py` (the stores a scene begins from), `take_own.py` (`take_all` for many), `give_back.py`, `boxes_of.py` (a cell's boxes whichever way it is kept), `shared_sides.py` (`joints_of`, `share_sides`).

- No start lays a grid. `three_cells` puts its joint at the place between its volumes: the approved crossing bench, cells `line_cells()`, slots 0, 1, 2.
- Dealing must sum to the cell's total to the quantum. The left-over quanta go one each from box 0 up.
- `give_back` moves slots: never in a store with collapses.
- A joint (minus total) is dealt like a volume, the sign kept.
- A cell is laid by its place (`laid_at`), so neighbours' facing fluid agrees.
