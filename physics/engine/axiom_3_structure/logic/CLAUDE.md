# Axiom 3, logic

`starts.py`, `first_volume.py` (a scene's stores), `take_own.py`, `seat.py` (many at once, on the card), `spare.py` (a step's work arrays), `give_back.py`, `boxes_of.py`, `joints_of.py`, `kept.py` (a store to a file and back), `roomier.py` (a universe into a bigger store).

- No start lays a grid. `three_cells` puts its joint at the place between its volumes: the approved crossing bench, cells `line_cells()`, slots 0, 1, 2.
- Dealing must sum to the cell's total to the quantum. The left-over quanta go one each from box 0 up.
- A joint (minus total) is dealt like a volume, the sign kept.
- No cell is laid by its place: the sign alone says which way its whirls turn.
